# Neovim — комбінації клавіш

`<leader>` — це **пробіл**. Тобто `<leader>e` = пробіл, потім `e`.

Українська розкладка в нормальному режимі працює: клавіші читаються за
фізичним положенням (`пж` = `g;`, `ьф` = `ma`). Друкувати літери це не заважає.

## Перемикання між панелями

Neo-tree відкривається **зліва**, текст — справа. Звідси й напрямок:

| Клавіші | Дія |
|---|---|
| `Ctrl-h` | перейти в ліву панель (з тексту → у файловий менеджер) |
| `Ctrl-l` | перейти в праву панель (з файлового менеджера → у текст) |
| `Ctrl-j` / `Ctrl-k` | перейти у панель нижче / вище |
| `Ctrl-w` `p` | стрибнути в попередню панель і назад (перемикач між двома) |

Якщо панелей більше двох, `Ctrl-w` `p` — найшвидший спосіб скакати туди-сюди.

## Панелі iTerm2 (поза Neovim)

Це вже не Neovim, а сам термінал — рівнем вище. ⌘ термінал не перехоплює,
тому ці комбінації працюють навіть коли фокус усередині Neovim чи Claude.

| Клавіші | Дія |
|---|---|
| `⌘ ⌥ ←` `→` `↑` `↓` | перейти в панель у цьому напрямку |
| `⌘ ]` / `⌘ [` | наступна / попередня панель по колу |
| `⌘ ⇧ Enter` | розгорнути поточну панель на весь екран (і назад) |
| `⌘ D` | розділити вертикально (панель справа) |
| `⌘ ⇧ D` | розділити горизонтально (панель знизу) |
| `⌘ 1` … `⌘ 9` | перейти на вкладку за номером |

`⌘ ⇧ Enter` — найкорисніше: коли логи в вузькій панелі нечитабельні,
розгортаєш її на весь екран, читаєш, тим самим хоткеєм повертаєш назад.

Стрибок одразу в конкретну панель (`⌘ ⌥ 1`, `⌘ ⌥ 2`) вмикається вручну:
Settings → Keys → Key Bindings, дія «Select Split Pane by number».

## Файловий менеджер (neo-tree)

| Клавіші | Дія |
|---|---|
| `<leader>e` | відкрити / закрити дерево файлів |
| `<leader>E` | відкрити дерево і підсвітити в ньому поточний файл |
| `H` | *(всередині дерева)* показати / сховати приховані та gitignored файли |
| `gs` | *(всередині дерева)* пошук по вмісту файлів у папці під курсором |
| `a` / `d` / `r` | *(всередині дерева)* створити / видалити / перейменувати файл |

## Вікна та вкладки

| Клавіші | Дія |
|---|---|
| `<leader>\|` | розділити вікно вертикально |
| `<leader>-` | розділити вікно горизонтально |
| `<leader>wd` | закрити поточне вікно |
| `<leader>wm` | розгорнути поточне вікно на весь екран (і назад) |
| `Shift-h` / `Shift-l` | попередній / наступний відкритий файл |
| `<leader>bd` | закрити поточний файл |
| `<leader>,` | список відкритих файлів |
| `<leader>fr` | недавно відкриті файли |

## Термінал і Claude Code

| Клавіші | Дія |
|---|---|
| `<leader>ac` | відкрити / сховати Claude Code |
| `<leader>at` | відкрити / сховати звичайний термінал |
| `Ctrl-q` `c` | *(з термінала)* перемкнутись на Claude Code |
| `Ctrl-q` `t` | *(з термінала)* перемкнутись на звичайний термінал |
| `Ctrl-q` | вийти з режиму термінала в нормальний режим (скрол, копіювання) |
| `Esc` `Esc` | те саме, але Claude іноді перехоплює Esc |

## Вискочити в шелл і повернутися

| Клавіші | Дія |
|---|---|
| `Ctrl-z` | кинути Neovim у фон і опинитися в шеллі, з якого він запущений |
| `fg` | *(у шеллі)* повернутися в Neovim, курсор на тому самому місці |
| `:!команда` | виконати одну команду, не виходячи з редактора |
| `:!!` | повторити останню таку команду |

`Ctrl-z` повертає тебе **в той самий шелл з усією його історією** — стрілка
вверх працює як завжди. Нічого не втрачається: Neovim просто спить у фоні,
усі відкриті файли й незбережені зміни на місці. `fg` будить його назад.

Працює, якщо Neovim запущений з термінала (не як окремий застосунок).
Якщо у фоні кілька програм — `jobs` покаже список, `fg %1` підніме потрібну.

## Навігація по коду

Переходи працюють через ctags — індекс без мовного сервера, тому на
однакових іменах покаже список кандидатів.

| Клавіші | Дія |
|---|---|
| `gd` | перейти до оголошення слова під курсором |
| `<leader>sy` | пошук по всіх символах проєкту (функції, класи, методи) |
| `*` / `#` | наступна / попередня згадка слова під курсором **у цьому файлі** |
| `n` / `N` | продовжити стрибати по згадках |
| `<leader>sw` | усі згадки слова **по всьому проєкту** |

## Повернутися туди, де вже був

| Клавіші | Дія |
|---|---|
| `Ctrl-o` | назад на попереднє місце |
| `Ctrl-i` | вперед |
| `` `` `` | перемикач між двома останніми місцями |
| `g;` | назад на місце, де редагував |
| `g,` | вперед по місцях редагування |
| `gi` | туди, де востаннє друкував, одразу в режим вставки |
| `<leader>sj` | список усіх місць, де був курсор |
| `ma` / `` `a `` | поставити закладку `a` / стрибнути на неї |
| `<leader>sm` | список усіх закладок |

## Перейменування та заміна

| Клавіші | Дія |
|---|---|
| `<leader>rn` | перейменувати слово під курсором **у цьому файлі** |
| `<leader>rc` | те саме, але питає підтвердження на кожному збігу |
| `<leader>sr` | заміна по всьому проєкту (grug-far, з прев'ю) |

При `<leader>rn` всі збіги підсвічуються наживо, поки набираєш нове ім'я.
`Enter` застосовує, `Esc` скасовує.

## Пошук

| Клавіші | Дія |
|---|---|
| `<leader><space>` | знайти файл у проєкті |
| `<leader>/` | пошук тексту по проєкту |
| `<leader>sg` | те саме |
| `<leader>sw` | пошук слова під курсором |

## Копіювання шляху до файлу

| Клавіші | Дія |
|---|---|
| `<leader>cp` | повний шлях |
| `<leader>cr` | шлях відносно проєкту |
| `<leader>cl` | шлях з номером рядка |
